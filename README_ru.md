# Secret Drop

Минимальный веб-сервис для шаринга секретов: авторизованный пользователь вставляет текст в форму, сервис сохраняет его как отдельный `.txt` файл на диск и возвращает ссылку, по которой этот секрет можно открыть.

## Запуск

```bash
cp .env.example .env
nano .env
mkdir -p secrets
docker compose up -d --build
```

Получить временный адрес Cloudflare Tunnel:

```bash
docker compose logs -f cloudflared
```

При старте `cloudflared` напечатает временный hostname вида `trycloudflare.com`. Открой этот URL, чтобы зайти в приложение по HTTPS.

Туннель временный, поэтому после перезапуска публичный hostname может измениться.

## Как работает шаринг

- `push`: открыть `/`, пройти Basic Auth и сохранить секрет
- `pull`: после сохранения приложение покажет ссылку вида `/s/<filename>.txt`
- любой, у кого есть эта ссылка, сможет открыть конкретный секрет без Basic Auth

Ссылка собирается из хоста входящего запроса, поэтому корректно работает за временным Cloudflare Tunnel hostname.

## Где лежат секреты

На хосте:

```text
./secrets/*.txt
```

Посмотреть:

```bash
ls -la secrets/
cat secrets/<filename>.txt
```

## Остановка

```bash
docker compose down
```

Файлы в `./secrets` сохраняются после остановки, удаления или перезапуска контейнера.
