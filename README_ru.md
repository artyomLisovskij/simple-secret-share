# Secret Drop

Минимальный веб-сервис для шаринга секретов по HTTPS через Cloudflare Tunnel.

Авторизованный пользователь вставляет текст в форму, шифрует его в браузере паролем, а сервис сохраняет только ciphertext. Ссылки на чтение требуют Basic Auth, а для просмотра секрета нужен ещё пароль шифрования (расшифровка в браузере).

## Преимущества

- Без публикации портов на хост: приложение доступно только в Docker-сети, наружу — через Cloudflare Tunnel
- Cloudflare quick tunnel без аккаунта: временный публичный endpoint без регистрации в Cloudflare
- Автоматический случайный hostname `trycloudflare.com` с HTTPS/TLS
- Basic Auth и для создания, и для открытия секретов
- Шифрование на фронтенде через Web Crypto API без сторонних JavaScript-библиотек
- Push и pull зашифрованных секретов по ссылкам
- Опциональное название секрета, которое попадает в имя файла и в share URL
- Опциональные one-time ссылки и TTL, с режимами reusable / без срока действия
- Расшифровка только в браузере или через CLI; пароль шифрования на сервер не отправляется
- На диске хранится только ciphertext (`./secrets/*.enc`)

## Требования

- Docker
- Docker Compose

## Запуск

```bash
chmod +x start.sh
./start.sh
```

Скрипт создаст `.env` из `.env.example` при необходимости, поднимет стек и напечатает временный публичный URL, когда он появится.

Можно запустить вручную:

```bash
cp .env.example .env
nano .env
mkdir -p secrets
docker compose up -d --build
docker compose logs -f cloudflared
```

Перед использованием задай в `.env` надёжный `BASIC_PASS`.

## Как работает шаринг

- `push`: открыть `/`, пройти Basic Auth, при желании указать название/TTL/one-time, ввести секрет и пароль шифрования
- браузер шифрует секрет до отправки; сервер хранит только ciphertext и метаданные ссылки
- если название задано, оно дописывается в имя файла (`...-<name>.enc`)
- `pull`: открыть `/s/<filename>.enc` с Basic Auth, затем ввести пароль шифрования на странице
- расшифровка выполняется в браузере; пароль шифрования на сервер не отправляется
- one-time секреты удаляются после первой успешной расшифровки; истёкшие удаляются автоматически

Зашифрованный JSON также доступен по `/s/<filename>.enc/raw` (тоже за Basic Auth).

## CLI расшифровки

```bash
docker compose run --rm decrypt
```

Утилита покажет список зашифрованных файлов в `./secrets`, предложит выбрать файл, запросит пароль и выведет plaintext в stdout.

## Где лежат секреты

На хосте:

```text
./secrets/*.enc
```

Файлы сохраняются после остановки, удаления или перезапуска контейнеров.

## Остановка

```bash
docker compose down
```
