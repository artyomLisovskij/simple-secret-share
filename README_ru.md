# Secret Drop

Минимальный веб-сервис для шаринга секретов по HTTPS через Cloudflare Tunnel.

Авторизованный пользователь вставляет текст в форму, шифрует его в браузере паролем, а сервис сохраняет только ciphertext. Ссылки на чтение требуют Basic Auth, а для просмотра секрета нужен ещё пароль шифрования (расшифровка в браузере).

## Возможности

- Basic Auth для создания и чтения
- Шифрование/расшифровка в браузере через Web Crypto (без npm)
- Зашифрованные файлы на диске (`AES-256-GCM` + `PBKDF2-SHA256`)
- Временный публичный HTTPS URL через Cloudflare quick tunnel
- CLI-утилита на Go для расшифровки файлов

## Требования

- Docker
- Docker Compose

## Запуск

```bash
chmod +x start.sh
./start.sh
```

Скрипт создаст `.env` из `.env.example` при необходимости, поднимет стек и напечатает временный публичный URL, когда он появится.

Можно запустить вручную:

```bash
cp .env.example .env
nano .env
mkdir -p secrets
docker compose up -d --build
docker compose logs -f cloudflared
```

Перед использованием задай в `.env` надёжный `BASIC_PASS`.

## Как работает шаринг

- `push`: открыть `/`, пройти Basic Auth, при желании указать название, ввести секрет и пароль шифрования
- браузер шифрует секрет до отправки; сервер хранит только ciphertext
- если название задано, оно дописывается в имя файла (`...-<name>.enc`)
- `pull`: открыть `/s/<filename>.enc` с Basic Auth, затем ввести пароль шифрования на странице
- расшифровка выполняется в браузере; пароль шифрования на сервер не отправляется

Зашифрованный JSON также доступен по `/s/<filename>.enc/raw` (тоже за Basic Auth).

## CLI расшифровки

```bash
docker compose run --rm decrypt
```

Утилита покажет список зашифрованных файлов в `./secrets`, предложит выбрать файл, запросит пароль и выведет plaintext в stdout.

## Где лежат секреты

На хосте:

```text
./secrets/*.enc
```

Файлы сохраняются после остановки, удаления или перезапуска контейнеров.

## Остановка

```bash
docker compose down
```
